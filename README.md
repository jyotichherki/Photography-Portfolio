# VisuaLens Photography Portfolio

VisuaLens is a modern and responsive photography portfolio website built using HTML, CSS, and JavaScript. It showcases creative photography through an elegant masonry-style gallery.

## Features
- Responsive masonry image gallery
- Interactive category filtering
- Image hover zoom animations
- Full-screen image lightbox
- Previous and next image navigation
- Keyboard navigation support
- Responsive navbar
- About and contact sections

## Technologies Used
- HTML5
- CSS3
- JavaScript
- CSS Grid and CSS Columns
- Flexbox
- DOM Manipulation

## Skills Learned
Gallery Layout, Image Styling, CSS Animations, Responsive Design, Event Listeners, and JavaScript DOM Manipulation.

## How to Run
1. Clone this repository.
2. Open the folder in VS Code.
3. Open index.html using Live Server.
